# Сборка и подпись

## Что подписывается

Windows-сборка StreamKit (`StreamKit.exe` и сопутствующие файлы), публикуемая
в GitHub Releases в виде архива `StreamKit-windows.zip`.

## Процесс сборки

* Артефакты собираются исключительно в CI — GitHub Actions, файл
[`.github/workflows/build.yml`](.github/workflows/build.yml).
* Сборка запускается по тегу вида `v\*` и выполняется на `windows-latest`
с помощью PyInstaller из исходников этого репозитория.
* Локально собранные артефакты на подпись не отправляются.
* Приватный ключ хранится в HSM на стороне SignPath Foundation.
Проект ключ не хранит и доступа к нему не имеет.

## Роли (проект с одним сопровождающим)

* **Authors** — имеют право коммита и могут менять репозиторий без
дополнительного review:

  * https://github.com/samurattv
* **Reviewers** — проверяют изменения, предложенные извне:

  * https://github.com/samurattv
  * Правило: все внешние pull request проверяются сопровождающим до слияния.
* **Approvers** — подтверждают каждый запрос на подпись:

  * https://github.com/USERNAME
  * Правило: каждый запрос на подпись требует явного подтверждения
сопровождающим.

## Зависимости

Все сторонние компоненты — открытые:

|Пакет|Лицензия|Назначение|
|-|-|-|
|numpy|BSD-3-Clause|вычисления|
|sounddevice|MIT|вывод звука|
|mss|MIT|снимок области экрана|
|psutil|BSD-3-Clause|определение запущенных игр|
|obsws-python|GPL-3.0|связь с OBS/PRISM|
|truststore|MIT|системные сертификаты|
|torch|BSD-3-Clause|движок синтеза речи|

Модель синтеза речи Silero не входит в состав сборки — она загружается
пользователем при первом запуске с сайта разработчика модели.

## Проприетарного кода нет

Весь код проекта опубликован в этом репозитории под лицензией MIT.
Собственных закрытых компонентов, а также кода, опубликованного
сопровождающим или связанными лицами вне открытых лицензий, проект
не содержит.
