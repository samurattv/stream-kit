# StreamKit

Три вещи, которые стример обычно делает руками — и забывает: озвучка чата, переключение сцен и нарезка хайлайтов. StreamKit делает их сам, локально и бесплатно.

Работает с PRISM Live Studio и OBS через obs-websocket.

## Что умеет

**Озвучка чата.** Читает чаты Twitch и YouTube голосами [Silero TTS](https://github.com/snakers4/silero-models) — локально, без облаков и подписок. Каждому зрителю можно закрепить свой голос или выдавать случайный. Ссылки, эмодзи и команды ботов отсеиваются, латиница транслитерируется, чатовый сленг читается по-человечески.

**Автосцены.** Следит за тем, какая игра запущена, и сам переключает сцену: лобби, игра, простой. Заодно поднимает буфер повтора, когда игра идёт, и опускает, когда закрыта.

**Автоклипы League of Legends.** Берёт события из официального Live Client Data API — точно и без нагрузки. Ловит убийства, ассисты, мультикиллы, драконов, баронов и эйсы.

**Автоклипы Valorant.** У Valorant нет API для событий в реальном времени, поэтому StreamKit смотрит на киллфид: строки с твоим участием игра подсвечивает сплошной плашкой, и её видно по длине непрерывной цветной полосы. Ловятся убийства, ассисты и смерти. Никаких инжектов и чтения памяти — только снимок области экрана.

## Установка

### Готовая сборка для Windows

Скачай `StreamKit-windows.zip` из [последнего релиза](https://github.com/samurattv/stream-kit/releases/latest), распакуй в любую папку и запусти `StreamKit.exe`. Python не нужен.

Модель озвучки (~100 МБ) скачается сама при первом запуске, настройки лежат в `config.json` рядом с программой. Сборка пока не подписана, поэтому Windows SmartScreen может предупредить о неизвестном издателе: нажми «Подробнее» → «Выполнить в любом случае».

### Из исходников

Нужен Python 3.10 или новее.

```bash
git clone https://github.com/samurattv/stream-kit.git
cd stream-kit
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
python run.py
```

## Настройка

1. В PRISM или OBS включи **WebSocket-сервер** и скопируй пароль (Инструменты → WebSocket Server Settings).
2. Там же включи **буфер повтора** в настройках вывода — без него клипы сохранять некуда. После включения программу записи надо перезапустить.
3. В StreamKit на вкладке «Основное» впиши канал Twitch и пароль, нажми «Загрузить из PRISM» и выбери сцены.
   Чтобы озвучивать ещё и YouTube, впиши в блоке «YouTube» ID трансляции (или ссылку на неё) и API-ключ — см. [ниже](#чат-youtube).
4. Для Valorant на своей вкладке нажми «Указать область киллфида» и обведи правый верхний угол.
5. Нажми **СТАРТ**.

Настройки сохраняются в `config.json` рядом с программой.

### Чат YouTube

Чат читается через официальный YouTube Data API v3. Нужен свой API-ключ: [Google Cloud Console](https://console.cloud.google.com/) → создать проект → включить **YouTube Data API v3** → «Учётные данные» → «Ключ API» (лучше ограничить его только этим API). Ключ хранится в `config.json` на твоём компьютере.

- Чат есть только у идущей трансляции. Если эфир ещё не начался, StreamKit каждые 15 секунд пробует снова.
- Бесплатная квота API — 10 000 единиц в день. Чат опрашивается не чаще раза в 8 секунд, этого хватает примерно на 5–6 часов эфира. Когда квота кончится, об этом напишет журнал, а Twitch продолжит работать.
- История чата до подключения и суперчаты не озвучиваются; команды зрителей (`!голос`, `!тихо`) работают как в Twitch.

### Подбор порогов для Valorant

Включи «Режим проверки» — программа будет писать замеры в журнал, но не сохранять клипы. Играешь катку и смотришь на первое число в строке: в спокойные моменты полоса близка к нулю, на событиях подскакивает до сотен пикселей. Порог ставится между этими значениями.

Длина полосы зависит от разрешения экрана, так что на другом мониторе её надо подобрать заново.

## Как это устроено

```
streamkit/
├── config.py      настройки и config.json
├── textutils.py   подготовка сообщений чата к озвучке
├── voices.py      голоса, эффекты и громкость озвучки
├── obs.py         связь с PRISM/OBS, переподключение при обрыве
├── workers.py     фоновые модули: чаты Twitch и YouTube, сцены, клипы
├── avatar.py      сервер аватара и страница с трекингом лица
└── ui.py          окно на customtkinter
```

Каждый модуль — отдельный поток с флагом остановки. Связь с OBS общая, с автоматическим переподключением. Никаких внешних сервисов: всё работает на локальной машине.

## Трансляция через свой сервер

Если вещаешь на YouTube и Twitch одновременно, можно отправлять в OBS один поток на свой сервер, а он раздаст его на обе площадки без перекодирования. В папке [`server/`](server/) лежит готовая установка для Docker: RTMP-сервер и веб-панель, где каждый стример сам вводит свои ключи (вход по приглашению, пароль и 2FA). StreamKit при этом остаётся на ПК, озвучка попадает в эфир через OBS. Подробности и инструкция по установке — в [server/README.md](server/README.md).

## Ограничения

- Windows. На Linux и macOS не проверялось.
- Valorant должен работать в оконном режиме без рамки — в эксклюзивном полноэкранном захват экрана отдаёт чёрный кадр.
- Русские модели Silero распространяются по лицензии CC BY-NC (некоммерческое использование). Мультиязычные модели `v5_cis_base` — под MIT.
